# 広告問い合わせの粗利追跡

`ad-lead-quality-template.csv` をGoogleスプレッドシートへ読み込み、問い合わせ1件につき1行を追加します。LPフォームから届く `utm_campaign`、`utm_term`、`gclid` と、Google広告の広告グループ・検索語句を可能な範囲で記録してください。

週次で「広告費 ÷ 問い合わせ数」だけでなく、広告グループ別の現調率、成約率、粗利合計、広告費に対する粗利を確認します。顧客情報は公開リポジトリへ保存せず、非公開のスプレッドシートだけで管理してください。

広告登録用の候補は `google-ads-keywords.csv`、除外候補は `google-ads-negative-keywords.csv`、広告文案は `google-ads-ad-copy.md` にまとめています。検索語句の実績を確認できない語は、候補ファイルにあっても一括適用せず、週次レビューで判断してください。
